# Newcleo

> Newcleo is a nuclear energy company founded in September 2021, headquartered in Paris,
> that designs small modular lead-cooled fast reactors (LFR) fuelled with mixed oxide (MOX)
> fuel made from reprocessed spent nuclear fuel. Newcleo publishes **no public API and no
> developer program**. This file is generated by API Evangelist from the public surface;
> it is not published by Newcleo.

## API surface

- No public API. There is no developer portal, no documentation host, and no published
  OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, MCP server or A2A agent card.
- www.newcleo.com is a client-side React application. The server returns a 354-byte HTML
  shell — and HTTP 404 with that same shell for every sub-path — with all content loaded
  at runtime from a private Azure API Management Contentful proxy.
- The only API endpoints referenced in the site bundle are website form handlers
  (contact-us, investor, supply-chain, user-admin, upload-investor) on
  newcleo-web-apim-prod.azure-api.net, gated behind an Ocp-Apim-Subscription-Key. They are
  the website's private backend, not an offered developer API.

## Open source

- [newcleo-dev-team on GitHub](https://github.com/newcleo-dev-team): 9 public repositories
  of scientific/engineering software for reactor physics and liquid-metal thermal hydraulics.
- [lbh15](https://pypi.org/project/lbh15/): the one library published to a package registry —
  liquid metal properties from the OECD/NEA Lead-bismuth Eutectic handbook (LGPL-3.0).
- [lbh15 documentation](https://newcleo-dev-team.github.io/lbh15/)
- [glow](https://github.com/newcleo-dev-team/glow): Geometry Layout Oriented Workflow, with
  [documentation](https://newcleo-dev-team.github.io/glow/). Source-distributed only.
- [tugui](https://github.com/newcleo-dev-team/tugui): GUI for postprocessing TRANSURANUS
  fuel performance output.
- [dassh_nc](https://github.com/newcleo-dev-team/dassh_nc): Ducted Assembly Steady State
  Heat Transfer Software.
- [nchainplotter](https://github.com/newcleo-dev-team/nchainplotter): nuclide chain plotter.
- [SOURCES4D](https://github.com/newcleo-dev-team/SOURCES4D): fork of LANL/SOURCES 4D.
